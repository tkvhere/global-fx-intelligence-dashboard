# Demonstration Script

## Live demonstration plan

1. Open the application landing page and show the overview dashboard.
2. Explain the live rate data and the supported currency universe.
3. Navigate to the rates page and display the current conversion table.
4. Demonstrate the converter tool with a sample currency pair.
5. Show historical analytics and explain the daily change summary.
6. Display the volatility card and explain the risk signal.
7. Move to the forecast page and review the forecast trend and model output.
8. Open the alerts page and show how alert thresholds are created and toggled.
9. Summarize the project architecture and the business value of the solution.

## Suggested speaking points

- The dashboard combines market intelligence and AI-driven forecasting.
- The solution is practical, full-stack, and immediately usable.
- The project demonstrates a real working pipeline rather than static mock data.
